Lector Universal User Guide

Lector Universal lets you read books and documents, listen to audiobooks and podcasts and follow the news, all designed for use with TalkBack. This guide opens in the reader itself: move through its sections with the navigation bar (choose “Headings”) or with the Contents button.

Getting started

How it works with TalkBack

  • Each book, folder, article or episode in a list is a single element that says everything important (for example, its status, title and date). Double-tap it to open it.
  • Its other actions are in the TalkBack actions menu. If you double-tap and hold, a menu opens with all its actions.
  • Actions say what they will do depending on the state: “Remove from favorites” if it is already a favorite, “See in Subscriptions” if you are already subscribed, “Already in your library: open it” if you already saved it.
  • In Settings, TalkBack actions, you choose which actions appear in each place and in what order.
  • Selectors and speeds are adjustable controls: with focus on them, swipe up or down with one finger to change the value; double-tap them to choose from a list.
  • Anything that takes a few seconds shows the “One moment, please…” window with a Cancel button.
  • When you close a window or a menu, focus returns to the element you opened it from.

Adding books

In the Library, tap Add books, at the top right. You have these options:

  • Add files: opens the Android file picker to choose one or more files. If you choose just one, it opens straight away.
  • Add a folder: adds the books in a folder and its subfolders. Then you choose between creating a library folder for each subfolder, adding all the books without creating folders, or adding them and watching the folder so new books are added automatically.
  • Search for books on the whole device (optional): finds all your EPUB and PDF files (or all books and documents, or audio too, in More options, What to search for) on the phone's storage and the card, whatever folder they are in. The first time it explains what it is for and takes you to Android settings to grant access to all files; if you do not, the app works the same. Each file says whether it is already in your library, its format, folder and size, and you can filter by name or folder. Tapping one adds it to the library (without moving it) and opens it; its actions also add it to a library folder or show its information. “Add all to the library” adds the ones in the list that are missing.
  • Scan a document with the camera (OCR): take photos of the pages; when you finish, the text is recognized and opens as a new document. If the phone has Google services, you choose between “With voice guidance (no Google services)” and “With Google’s scanner”; if it doesn't, voice guidance opens straight away.
  • A web page or a text (in Shared): takes you to the Shared section, where web pages and copied or typed texts are opened.

New items go to the library folder you have open and get the type of the tab you are on: a PDF added on the Documents tab is a document.

What you open or share from another app (file manager, email, browser) with “Open with” or “Share”, choosing Lector Universal: read, goes to the Shared section. From there you move it to the library if you want to keep it. If you prefer it to go straight to the library, as before, change it in Settings, Library, Shared.

Android does not let you choose the whole Download folder or the root of the storage. Keep your books in a subfolder (for example Documents/Books) and choose that one.

Scanning with voice guidance

It works without Google services and offline. The first time, it asks for permission to use the camera.

  • Put the page on a table and hold the phone above it, about 30 centimetres away. The guidance tells you if the text goes off one side and which way to move the phone, if you need to move it closer or further away, or if no text can be seen.
  • When the whole page is in view and still, it says “Good, hold still” and takes the photo by itself, with a beep. Then put the next page: if it sees the same page again, it tells you and doesn't repeat it.
  • Capture now takes the photo without waiting; Flashlight turns it on or off.
  • Finish (N pages) says how many you have. When you tap it, the document is created with the text of all the pages and opens.

Home, the sections and the side menu

The app has five sections that work the same way: Library, Shared, Podcasts, News and Radio. In all of them, the “Open menu” button is at the top left and the section's tabs are at the bottom, always all visible.

Home

This is the screen the app opens with: the most useful things from each section on a single screen, in the order you choose in Settings, Home and sections. Each section starts with a heading with its name and a summary (for example, “Podcasts, 3 new episodes”); with TalkBack's heading navigation you jump from one to the next, and double-tapping the heading opens the whole section (“See all”). Under each heading:

  • Library: the books you are reading, with their progress. Double-tap to open one; the TalkBack actions are the same as in the Library (read aloud, information…).
  • Shared: what you still have to read of what you shared with the app. Double-tap to open it; the actions are the same as in Shared.
  • Podcasts: the episodes you left halfway, the queued ones and the new ones. Double-tap to listen; the actions add to or remove from the queue, mark as played and remove from New.
  • News: the latest unread articles. Double-tap to read one; the actions are the same as in News.
  • Radio: your favourite stations (or, if you have none yet, the ones you played last). Double-tap to listen; the one playing says “Playing”.

At the bottom, the mini player, as in the sections. In Settings, Home and sections you choose how many items each section shows (3, 5 or 10) and which sections appear.

Mini player

If something is playing or paused (a book or an article read aloud, an audiobook, an episode or the radio), a line appears above the tabs with what is playing and its state, “Pause” or “Resume” and “Stop”. Tapping what is playing takes you back to its screen. It stays there when you change section, so you can listen to the radio while you browse the news. Only one thing plays at a time: if you start something else, the mini player switches to it. The notification and the lock screen also always open what is playing.

Side menu

The side menu has Home and the five sections at the top, in the order you choose in Settings; the one you are using says “selected” and, when you open the menu, focus goes straight to it. Below are Statistics, Settings, User guide and About. If you choose the section you are already in, you go back to its first tab. Back closes the menu.

  • Statistics: those of every section, in the same order. For each one, the time today, in the last 7 days, this month and in total, and your streak of consecutive days. Library: reading time, words, books finished and in progress, and the most read. Podcasts: listening time, episodes finished, subscriptions, new, queued, downloaded and the most played podcasts. News: time reading or listening to the news, articles opened, feeds, unread, read, favourites and read later. Radio: listening time, stations played, favourites, songs logged, recordings and your most played stations. Each section and each part starts with a heading.
  • Settings: those of the whole app, with tabs at the bottom: General and one per section (Library, Shared, Podcasts, News and Radio).
  • About: the version, and the Check for updates and What's new buttons.

With Back: inside a folder you go up to the previous one; in another tab you go back to the first one; from the first tab of a section you go back to Home; and from Home you leave the app. In Radio, if you have no favourites yet, the section opens on Explore, and Back from there already takes you to Home.

Library

It has four tabs: Reading, Library, Bookmarks and Catalogs.

Reading

The books you have opened, starting with the last one. In More options, “Clear the Reading list” empties it; the books stay in the library with their position.

Library

It works like a file explorer. At the top it says where you are (for example “Documents › Notes”); then come the type tabs, the search box and the folders and books in that folder. Tap a folder to go in; the first row, “Up to…”, goes back to the previous one (so does Back).

Types: books, documents, audiobooks and web pages

So that novels are not mixed with notes or presentations, everything in the library has a type: Book, Document, Audiobook or Web page, plus the types you create (for example “Notes”, “Magazines” or “Scores”). At the top of the Library tab there is a tab for each type, plus All. They are always fully visible: the ones that do not fit on the screen go into the last one, More, which opens the list of the rest and says which one you have chosen (“More: Web pages”).

  • The type is set automatically: EPUB, Kindle, FictionBook, DAISY, braille and comics are books; audiobooks and audio, audiobooks; presentations and spreadsheets, documents; pasted and scanned texts, documents; web pages, web pages; and downloads from a catalog, books. PDF, Word, RTF, text and HTML files that say nothing else are books or documents, as you choose in Settings, Library, Library and sync.
  • What you add while on a type's tab, or in one of its folders, gets that type.
  • Each book's Change type… action changes it (or leaves it “Automatic, by format”), and you can create a new type right there. It also works with several books at once and with a whole folder (“Change the folder's type…”).
  • Each type has its own folders: a folder created on the Documents tab is a documents folder and only appears there and in All. Older folders, of any type, appear on every tab where they have something (and, when empty, on all of them, so you can fill them). Moving a book to a folder of a type gives it that type.
  • In Settings, Library, Library tabs and types you choose which tabs are shown and in which order (each row is a switch and moves with Move up and Move down, like the sections), create your own types with the “New type” button, and rename or delete them. Deleting a type never deletes a book: its items go back to the type that matches their format.

Besides the type tabs:

  • New folder: creates a folder inside the one you have open (of that type, if you are on a type's tab). In the Collections view, this button is “New collection”.
  • Search by title or author: searches all folders of the type you are viewing; folders whose name matches also appear.
  • Show: switches from “By folder” to Everything without folders, Favorites, Reading, Not started, Finished, Want to read, Abandoned, Authors, Series or Collections, always of the type you are viewing. In those views each book says which folder it is in.
  • In Authors, Series and Collections you see the list of groups with how many books each has. Tap one to go in, as with a folder; the first row, “Up to…”, or Back return to the list. Inside a series, books are sorted by their number.
  • Sort, in the top bar: recently opened, title, author, recently added, progress, format or size.
  • If you watch folders, More options has “Look for new books in watched folders”.

Book and folder actions

Each book says its title, author, series (if it has one), format, status or progress and folder; in All and in Reading, also its type. Its actions: Select, Open, Read aloud (without opening it), Information, Move to a folder, Add to favorites, Mark as finished, Mark as unread, Reading status…, Collections…, Series…, Change type…, Voice for this book…, Remove from Reading, Edit title and author, Share file and Remove from library. Removing a book never deletes the file from the device, but it does delete its bookmarks and notes.

Reading status… chooses between not started, want to read, reading, finished and abandoned. Going back to “not started” deletes where you were, so it asks first.

The list no longer jumps when it refreshes: while the details of many newly added books are being read, TalkBack focus stays where you were.

Folders have Open, Read the folder, one after another (reads its documents aloud one after another, hands-free: when one ends it says “Next” and its title and starts the next), Rename, New subfolder, Move folder, Delete folder and Change the folder's type…. When you delete a folder, its books move to the parent folder.

Collections and series

  • Collections: group books as you like without taking them out of their folder, and a book can be in several. Create them with “New collection”, in the Collections view, or with a book's “Collections…” action, which shows a checkbox for each collection and the “New collection…” button.
  • Each collection has the Open, Rename and “Delete the collection” actions. When you delete it, its books stay in the library.
  • Series: filled in automatically if the book includes them (EPUB made with calibre, EPUB 3 and FB2). Otherwise, use the “Series…” action and type the name and the number separated by a comma, for example “The Foundation, 3”. Leave it empty to remove it.

Several books at once

Use a book's “Select” action; after that, tapping other books adds them to or removes them from the selection. The “N selected: actions” button lets you move them to a folder, change their type, add them to or remove them from favorites, change their reading status, put them in collections, mark them as finished or unread, remove them from the library, select all in the list or clear the selection.

Bookmarks

All the bookmarks and notes from all your books. Each one has Go to bookmark, Edit note, Copy and Delete.

Catalogs

Online book libraries (OPDS). Project Gutenberg (also its list of books in Spanish) and Internet Archive are included (its free books, also only the Spanish ones; lending books, which need an account and carry protection, are not shown). Internet Archive books are often scans: the best file available is downloaded (EPUB, PDF with text or the recognised text). Each catalog has Open, Edit and Delete.

Add catalog or library website: type a name (if you leave it empty, it is taken from the page) and the address. The “Type” button is set to “Find out when saving”: the app checks the address and, if it is an OPDS catalog (such as Calibre-Web or COPS on your Synology), lists it in the app; if it is a library’s website, it will open it in the app browser, just like Tiflolibros. You can also choose the type yourself. User name and password are only needed for catalogs that ask for them; on a library website you sign in on its own page.

Tiflolibros, Biblioteca Digital ONCE (ClubONCE) and the library websites you add open their website inside the app. You sign in yourself with your usual username and password (the app neither sees nor stores them; the session is remembered as in a browser). At ONCE, after signing in, go to Libros y películas and then Biblioteca Digital. When you download a book, it is saved automatically in your library with its title, and the app asks whether to open it: ZIPs with text open as a document, and those with audio or DAISY as an audiobook. Back returns to the previous page; More options has Reload, Go to the start page and Open in browser.

Inside a catalog, tap a list to go in; “Up” or Back return to the previous one, and Search looks for a title or author if the catalog allows it. When you tap a book you see its information and the “Download and read” button (and “Another format” if there are several): it goes into your library and opens. If you already have it, you can open it or download it again.

Shared

This section is for what you send to the app from other apps or from the internet so that it reads it to you, without mixing it with your library: a blog or magazine article, a text, a PDF someone sent you… In any app, use Share (or Open with) and choose Lector Universal: read. If it is a link, the main text of the page is downloaded, without menus; if it is a document, it is saved as it is; if it is text, it is saved as a document. Then it opens (or opens and starts reading aloud, or is just saved, depending on Settings).

It has three tabs: To read, Read and All (with a search box). Each item says first whether it is unread, read or how far you got, and then its title, its type, the website it comes from and when it arrived.

  • The Add to Shared button, at the top: open a web page, read copied text, or type or paste a text.
  • Read with Lector Universal: in any app, select some text and, in the menu that appears (sometimes inside the three dots), choose “Read with Lector Universal”. It is saved in Shared and starts being read aloud at once.
  • Read what is pending, one after another (in More options): reads aloud everything pending, from oldest to newest, one after another.
  • Each item's actions: Open, Read aloud, Move to the library… (you choose its type and folder), Mark as read or unread, Open in browser, Share, Copy link, Rename, Information and Delete.
  • In More options: Delete read items and Delete everything in Shared. In Settings, Shared tab, read items can be deleted automatically the next day, after a week or after a month.
  • What you move to the library is no longer in Shared and is never deleted with it.

Reading with TalkBack

On the reading screen, each paragraph is a TalkBack element:

  • Swipe right or left to move from paragraph to paragraph. With TalkBack's “Read from next item” the whole book is read and the text scrolls by itself.
  • Inside a paragraph, TalkBack's reading controls work: characters, words and lines.
  • Headings are real headings, so TalkBack's heading navigation also works. List items, tables, quotes, images and notes are announced as such.
  • If a paragraph has a bookmark, note or highlight, starts a page or matches the search, TalkBack says so after the text (Settings, Navigation and TalkBack, “What to say about each paragraph”).
  • Math formulas (MathML) are read in words, for example “x squared plus 1” or “fraction, a over b, end fraction”. If the book includes its own description of the formula, that is read instead.
  • Links are in TalkBack's links menu and in the paragraph actions. When you open a footnote reference, such as “[3]”, the note is shown in a window without losing your place, with the “Go to note” button.
  • The position is saved where the focus is. When you open the book again, focus goes to that paragraph.

With a braille display

Everything works the same with a braille display connected to TalkBack (TalkBack supports it over Bluetooth or USB without installing anything else). In the reader, each paragraph is one item: you read it whole on the display, scroll through it with its panning keys and move to the next or previous paragraph with the display’s navigation keys. The paragraph actions are also in TalkBack’s actions menu.

Paragraph actions

By default, a paragraph's TalkBack actions are: its links, Describe the image (if it is an image), Read aloud from here, Add or Remove bookmark, Add note, Copy paragraph, Next heading, Previous heading, Table of contents, Search in book, Go to and Leave the table, list or quote (only inside one). You can add Look up a word, next and previous element, Where am I, Select chapter text, Share paragraph, Explain this paragraph, Translate this paragraph, Highlight a passage, Copy several paragraphs and Quick mark, and change the order, in Settings, TalkBack actions, Reader paragraphs.

Double-tapping a paragraph opens the menu with all its actions. In Settings, Navigation and TalkBack, “When double-tapping a paragraph”, you can change it to read aloud from there, open its first link or do nothing.

Look up a word: you choose a word from the paragraph, or “The whole paragraph”, and then what to do: look it up in the Royal Spanish Academy dictionary (books in Spanish) or in Wiktionary, in Wikipedia, translate it, spell it, send it to other apps or copy it.

Leave the table (or the list or quote): goes to the first paragraph after it, without going through the remaining rows or items.

Copy several paragraphs: on the first one, “Mark the start of the copy”; on the last one, “Copy from the mark up to here”. Everything in between is copied.

Quick mark: “Set the quick mark here” saves one place per book without creating a bookmark, and “Go to the quick mark” takes you back. Useful to check something and come back.

Translate this paragraph: with Google Translate (if installed), with AI or with another app.

Highlight…: you choose “The whole paragraph” or one of its sentences, and then a category: Important, Question, Quote, Idea, To review or “Other category…”, where you type your own. The passage is shown underlined and TalkBack says “highlighted: category” after the paragraph. If the paragraph already has highlights, the same action offers “Remove the highlight…” for each one. It only works in the books in your library.

Navigation

The navigation bar

At the bottom of the reading screen there are three controls: Previous, the Navigate by selector and Next. On the selector, swipe up or down to change the element, or double-tap it to choose from the list. Each book remembers the last one you used in it (headings in one, paragraphs in another); books you open for the first time start with the last one you chose. Only the elements the document has are offered:

  • Paragraphs, headings and headings of each level, from 1 to 6.
  • Chapters (the table of contents entries) and pages (those of the printed book or the PDF).
  • Links, lists, list items, tables, quotes, images, footnote references, formulas, code blocks and separators.
  • Bookmarks, search results and 10 percent jumps.

Previous and Next say their full function, for example “Next level 2 heading”. When there are no more, a tone sounds and “No more…” is spoken. In Settings, Navigation and TalkBack, you can turn on wrap-around navigation and make the volume keys go to the previous or next element, the previous or next paragraph, or scroll the screen.

Reading buttons

The buttons are at the top: Contents, Search, Go to, Marks, Voice, Where, AI, List, Sleep, Appearance, Its voice, Info, Copy, Export and Settings. Those that don't fit go to the More options menu. In Settings, Navigation and TalkBack, you choose how many button rows are shown and which buttons always go to the More menu.

  • Contents (Table of contents): with the level and percentage of each entry. It opens with focus on the current chapter and has a field to filter.
  • Go to: a percentage (also relative, such as +10), a page, a paragraph number, the start or end of the document, and back to the previous position (or to the next one) after a jump.
  • Marks (Bookmarks and notes): add a bookmark or a note here, see the book's ones (with actions to edit the note or delete) and export them as text. If the book has highlights, also “Show the highlights”, to go to one, change its category (“Change the category” action) or delete it, and “Export the highlights by category”, which sends them as text to another app, grouped by category and with the place of each one.
  • Where (Where am I): chapter, page, percentage, paragraph and the time left listening with the voice.
  • List (List of elements): choose a type (headings, links, tables, pages, bookmarks…) and see them all with their text to go to any of them.
  • Appearance: larger text, smaller text and text colors.
  • Its voice (Voice and speed for this book): see Read aloud.
  • Info: title, author, format, words, paragraphs, headings, pages and the time to listen to it all.
  • Copy (Select chapter text): the chapter in a text field so you can move with the cursor, select and use “Copy selection” or “Copy all”.
  • Export: as text or to audio.

Search

The Search button opens a field with your search history and three options: match case, whole words only and regular expression. Without match case or regular expression, the search ignores accents (“cancion” finds “canción”).

Search goes to the next result and sets the navigation bar to “Search results”, so Previous and Next move through the results. Show all shows the list of results with their context.

Physical keyboard

With a Bluetooth or USB keyboard, on the reading screen:

  • H: next heading; 1 to 6: heading of that level. C chapter, P page, K link, L list, I list item, T table, Q quote, G image, O footnote reference, M formula, X code, S separator, B bookmark. With Shift, backwards.
  • Ctrl+F search; F3 and Shift+F3: next and previous result.
  • Ctrl+G go to; Ctrl+T table of contents; F7 list of elements; = where am I; Ctrl+I information.
  • Ctrl+B add or remove bookmark; Ctrl+Shift+B bookmarks; Ctrl+N note.
  • Ctrl+R or Ctrl+Space: read aloud or pause. Media keys: play, pause, next and previous.
  • Alt+Left and Alt+Right: previous and next position after a jump.
  • Ctrl+Home and Ctrl+End: start and end. Ctrl+plus and Ctrl+minus: text size.

In the player: Space plays or pauses; Ctrl+Left and Ctrl+Right, previous and next; Ctrl+Up and Ctrl+Down, speed; Ctrl+T chapters; Ctrl+B bookmarks; Ctrl+G go to a time.

Read aloud

Besides reading with TalkBack, the app can read with its own voice, sentence by sentence, even with the screen off. Start with the Voice button, with a paragraph's “Read aloud from here” action or with a library book's “Read aloud” action.

  • When you start with the Voice button, focus moves to the voice panel: Previous paragraph, Previous sentence, Pause, Next sentence, Next paragraph, the speed and Stop reading aloud.
  • The voice speed is adjustable: swipe up or down to change it in steps of 5, or double-tap it to choose it.
  • With TalkBack, the app doesn't move the focus while reading, so TalkBack doesn't talk over the voice. To bring focus to the paragraph being read, use the “Go to the paragraph being read” action of the Voice or Pause button. Without TalkBack, the sentence is highlighted and the text follows it.
  • When TalkBack speaks, the book lowers its volume and restores it afterwards. In Settings, General, Read aloud, “When TalkBack speaks”, you can choose to pause and resume afterwards, or to keep playing as is.
  • There is a notification with controls, also on the lock screen, and headphone buttons work.
  • If a paragraph is in another language, it is read with a voice for that language. Headings are read with a slightly higher pitch.
  • You can skip footnotes, web addresses and text in parentheses or brackets when reading (Settings, General, Read aloud).
  • If reading stops with the screen off, tap Settings, General, “Keep battery saving from stopping reading”.

Sleep timer

The Sleep button (Sleep timer) stops reading after some minutes or at the end of the chapter, lowering the volume at the end. You can also hold the Voice or Pause button (with TalkBack: double-tap and hold) to choose the timer and start reading with it straight away. With the timer on, shaking the phone restarts it; if it has just stopped reading, shaking resumes it. Turn it off in Settings, “Shake to extend the sleep timer”.

The general voice, each section’s voice and each book’s voice

The general voice (Settings, General, Read aloud) is the voice of the whole app: books, Shared and news. Its engine can be any installed one or ElevenLabs. Each section can have its own, which inherits from the general one whatever you do not change: Library voice (Settings, Library), Shared voice (Settings, Shared) and News voice (Settings, News). And each book or Shared item can have its own, which inherits from its section. For example: ElevenLabs as the general voice, a faster phone voice for the news and an English voice for a book in English.

Voice for this book

Each book can have its own voice. The Its voice button on the reading screen, or the Voice for this book… action in the library, opens a screen with the speech engine, the language of the voices in the list, the voice, speed, pitch, changing voice by paragraph language and the pause between paragraphs. Everything starts as “As in the Library” (or “As in Shared”): whatever you do not change follows its section’s voice and, what that does not change, the general voice; if you later change them, the book follows them. In Shared, the action is “Its voice…”. What you change applies only to that book: for example, an English voice for a book in English, or a faster speed for a book you already know. “Test the voice” speaks with your choices and “Remove everything of its own” goes back to what it inherits. It applies straight away, also while the book is being read. Changing the speed while reading changes the one in charge: the book’s if it has one, otherwise its section’s and, otherwise, the general one.

Pronunciation dictionary

In Settings, General, Read aloud, Pronunciation dictionary. Each rule says how a text is pronounced (for example “Dr.” as “doctor”). It applies to whole words, or as a regular expression; it can match case, be turned off and be tried before saving it. It only changes what the app's voice says, not the text.

Audiobooks and DAISY

Audiobooks (M4B, M4A, MP3, OGG, OPUS, FLAC and others, single files or in a folder) and DAISY books with audio open in the player. An audiobook made of several files in a folder, or a DAISY book in a folder, is added as a single book.

  • Each audiobook remembers its speed and position.
  • When resuming after a long pause, a few seconds are repeated so you don't lose the thread.
  • Headphone buttons skip chapters or jump a few seconds, according to Settings, Audiobooks and DAISY.
  • DAISY books with text show the text being played and have the Text button to read it on the reading screen.

The audio player

It is the same for audiobooks, DAISY, podcasts and news audio. From top to bottom:

  • The author or podcast, the chapter, the time and the position bar, which says for example “12 minutes of 45, 28 percent, 33 minutes left” (what is left, at the current speed). Swipe up or down to move forward or back 5 percent.
  • Back, Play or Pause, and Forward. Back and Forward jump the seconds chosen in Settings and say where you end up. Holding Play chooses the sleep timer and starts playing with it.
  • Previous, the Move by selector and Next. The selector chooses the unit: chapters, DAISY levels, pages, sentences, bookmarks, tracks or jumps of 1, 5 or 10 minutes (only those available in what you are listening to). Each button says what it does, for example “Next chapter”.
  • Speed, from 25 to 400 percent without changing the pitch: swipe up or down to change it in steps of 5, or double-tap it to choose it.
  • Chapters, Marks (add a bookmark or a note here and see the saved ones), Go to (a time), Sleep (timer) and Text (if available).
  • Go to a time says where you are and how long it lasts. Type a time (12 means minutes; also 12:30 or 1:02:30), a jump from where you are with + or - in front (+5:00, -1:30) or a part of the whole with % (50 % goes to the middle). If the time is past the end, it tells you.
  • Sleep (timer): a few minutes, the end of the chapter or, for podcasts, the end of the episode or after 2, 3 or more episodes. In Settings, Audiobooks and DAISY, “Automatic sleep timer” sets it by itself when you start listening between the hours you choose (for example, 23:00 to 07:00), and the app says so.
  • Unplugging the headphones pauses the audio. With “Resume when headphones connect” (Settings, Audiobooks and DAISY), it carries on if you plug them back in within 15 minutes.
  • In More options: Skip silence, Volume boost, Information, and Stop and close. For a podcast episode, also See the episode notes, Read the transcript and Mark as played and go to the next in the queue.

Podcasts

In the side menu, Podcasts. Its tabs are at the bottom: Subscriptions, Inbox, Queue, Episodes and Discover. At the top: Refresh and Add podcast (what is playing is in the mini player, above the tabs); in More options, Import OPML and Export OPML.

The tabs

  • Subscriptions: first your folders, then the podcasts without a folder. The “Order” button sorts them by hand, by name, by unplayed episodes or by latest published. Tap a podcast to see its episodes; there you have “Show all” or “Show only unplayed”, the episode order (newest or oldest first), “Podcast options” and a field to search episodes.
  • Inbox: new episodes. “All to the queue” and “Clear inbox” buttons.
  • Queue: what you are going to listen to, in order, and the total time left. “Play the queue” starts with the first one; when an episode ends, the next one follows. “Sort the queue” sorts it by date, by time left, by podcast, reversed or shuffled. “Clear the queue” empties it.
  • Episodes: the “Show” button chooses In progress (started but not finished), Downloads (with “Delete played episodes”), Favorites or History. Favorites and History have a search field.
  • Discover: the top podcasts, with a button to choose the category, and the “Search podcasts” and “Search episodes” buttons (single episodes from any podcast). “Search podcasts” searches Apple Podcasts and the open directories fyyd and gpodder.net, with no account: first the ones from Apple and then those only in the others. After a search: “New search” and “Back to top podcasts”.

If you have folders, Inbox, Queue and Episodes show the “Folder” button to see only the episodes of the podcasts in one folder, or of those without a folder. In the Queue, the time left is that of what is shown.

Podcast folders

  • Create: “New folder” button in the main Subscriptions list.
  • Folder actions (also with the “Folder options” button when you are inside): Open, Refresh the podcasts in the folder, Mark all as played, Rename, Delete folder, and Move up one position, Move down one position, Move to first and Move to last to sort them.
  • Delete: if the folder has podcasts, you choose between deleting only the folder (its podcasts are left without a folder) or deleting the folder and unsubscribing from its podcasts, along with their downloads.
  • Put a podcast in a folder: with “Move to a folder” or in Podcast settings, “Folder” button. The list offers “No folder”, your folders and “New folder…”, which creates it with the name you type.
  • When you subscribe, if you have folders, the app asks which one to put it in.

Podcast options

“Podcast options” (or holding the podcast) has: Move to a folder, the actions to sort it among those in its folder, Open, Refresh, Podcast settings, Mark all as played, Podcast information, Open in the browser and Unsubscribe.

Podcast settings: name, folder, its own speed, its own volume (no boost or +3 to +15 dB, for podcasts that sound very quiet; otherwise the player’s general boost), seconds of intro skipped at the start and before the end, whether new episodes are downloaded, where new ones go (inbox, the queue or nowhere), new episode notifications and pause (don't refresh it). Also its filters: only episodes with some words, none with other words and a minimum length (what does not pass is neither downloaded nor added to the inbox), and playing its episodes from oldest to newest, ideal for series.

Episode actions

Each episode says whether it is new, in the queue or downloaded, and how much you have played. Double-tap it to play it. Its actions: Play; Add to queue or to the start of the queue, or Remove from queue (in the Queue, also Move up, Move down, To the start and To the end of the queue); Download, Cancel the download or Delete the download; Mark as played or unplayed; Remove from inbox; Add to favorites; See the episode notes; Read the transcript (if it has one); Share; See the chapters (without playing: when you choose one, it starts from there); Play continuously from here (from oldest to newest, ideal for series); Mark older or newer episodes as played; and Go to the podcast.

If a download fails, the app retries it by itself up to three times and then tells you. The episode says “download failed” and has the action “Retry the download”.

In the episode notes, timestamps (for example 12:30) are links: when you open them, the episode plays from that moment.

In the transcript of a podcast you subscribe to, each paragraph starts with its time, which is also a link to that moment of the episode. If you open it from the player, focus goes to the paragraph of what is playing.

Search and subscribe

  • Add podcast: Search podcasts, By address (the podcast's RSS or its website) or Top podcasts.
  • Top podcasts and searches are by country. The country is worked out from the phone's SIM card and network (before, from the language, and phones set to “Spanish (United States)” got the United States podcasts, in English). In Discover, the Country button says which one is used and lets you choose another.
  • Tapping a podcast you found opens its page: information (author, episodes, how often it publishes, average length, whether it has transcripts or chapters…), the description and all its episodes, which you can play without subscribing. At the top: Subscribe (or See in Subscriptions), Web, Trailer, Share and Support, if available.
  • From Share in another app (browser, another podcast app), choose Lector Universal: subscribe in Podcasts to subscribe to that address.
  • Chapters are shown if the podcast publishes them or if they come inside the audio file, even if it isn't downloaded.
  • If downloads are Wi-Fi only in Settings and you are on mobile data, the app asks whether to download now with mobile data or wait for Wi-Fi.
  • Private podcasts (patron-only ones, for example): if the podcast asks for a user name and password, the app asks for them when you subscribe and uses them to refresh it.
  • Podcast account (Settings, Podcasts): syncs your subscriptions and where you are in each episode with gpodder.net or with Nextcloud's gPodder Sync. Choose the service, type your user name and password (and the address, for Nextcloud) and tap “Sync now”.

News

In the side menu, News. Its tabs are at the bottom: Unread, Feeds, Favorites, Read later and Search. At the top: Refresh and Add feed. Articles are read in the app's reader, but they don't go to the library unless you use “Save to the library”.

The tabs

  • Unread: “Read all aloud”, “Read headlines”, “Show” (unread, today, all or read) and “Folder: All folders”, which filters by folder.
  • Feeds: first your folders, with the unread articles and feeds in each; then the feeds without a folder. Inside a feed you have “Read all aloud”, “Read headlines”, “Show all” or “Show only unread” and “Feed options”.
  • Favorites and Read later, with “Read all aloud” and “Read headlines”.
  • Search: searches titles, summaries and authors (at least two letters). “Save search” and “Saved searches” let you repeat it.

Read all aloud opens the articles in the list one after another in the reader and starts reading them. It doesn't mark them as read when it starts: when you leave the reader, the ones you got to hear are marked (in Favorites and Read later they aren't marked). Read headlines reads only the headlines one after another, with their feed and date; each headline is a link that opens its article.

News folders

  • Create: “New folder” button in the main Feeds list.
  • Inside a folder: “Read all aloud”, “Read headlines”, “Add a feed to this folder” and “Folder options”.
  • Folder actions: Open, Read all aloud, Mark all as read (asks for confirmation), Rename, Delete folder, and Move up one position, Move down one position, Move to first and Move to last.
  • Delete: if the folder has feeds, you choose between deleting only the folder (its feeds are left without a folder) or deleting the folder and its feeds with all their articles.
  • Put a feed in a folder: with “Move to a folder” or in Edit feed, “Folder” button. The list offers “No folder”, your folders and “New folder…”.
  • When you subscribe to a feed outside a folder, if you have folders, the app asks which one to put it in.

Feed options

“Feed options” (or holding the feed) has: Move to a folder, the actions to sort it among those in its folder, Open, Refresh, Mark all as read (asks for confirmation), Edit feed, Feed information, Open in the browser and Delete the feed.

Edit feed: name, address (if the website changed it), folder, words that hide articles, only keep articles with some words, skip what already came from another feed (same link or same headline), notify of new articles, always download the full article from the website, open articles in the browser and pause (don't refresh it).

Adding feeds

  • Add feed: Search feeds by topic or name, By address (of the feed or its website: the app finds the RSS) or Recommended feeds.
  • By address you can also paste a YouTube channel (its address with @name, /channel/ or /c/), a YouTube playlist or the link of any video (also youtu.be and Shorts): the video's channel is followed. Videos are read with their description. Also a Reddit subreddit or user, a Mastodon account (also written as @user@server), a Bluesky profile or a groups.io group (the address of the group or of one of its messages: its RSS is followed and each message arrives as an article).
  • With the address of a website or one of its articles, the app looks for its RSS: only real feeds (comment feeds last, and nothing else websites announce) and checking that they work.
  • Facebook, Instagram, X, TikTok and other networks do not publish RSS, so they cannot be followed; the app says so.
  • From Share in another app (also from the YouTube app), choose Lector Universal: subscribe in News to subscribe to that address.

Article actions

Each article says whether it is unread, a favorite or saved for later, its title, the feed, when it was published and how long it takes to read, for example “3 minute read” (you choose what is said in Settings, News). Its actions: Open, Listen to the audio (if it has any), Mark as read or unread, Add to favorites, Read later, Download the full article, Open in the browser, Share, Save to the library, Move to the trash, Mark the ones below as read and Go to the feed.

Reading an article

News is read aloud with the News voice (Settings, News): engine, voice, speed, pitch, languages and pauses for the news, different from the books; whatever you leave as “As in the general voice” follows the general voice. In an article, the Its voice button opens that same screen. At the end of an article it says “End of the article”.

The buttons start with Voice, followed by Next, Previous (article), Favorite, Save (to the library) and Web; then the other reading buttons. The AI button summarizes the article or answers questions about it. With “Read aloud when opening an article” (Settings, News), it starts playing as soon as it opens.

If the feed only brings a summary, the app downloads the full article from its website when you open it, joining stories split across several pages. The “Download the full article” action tries again and says what happened, for example if it is for subscribers only.

More options in News

  • Mark all as read: all of them, or only those older than a day.
  • Rules and alerts: if a new article contains some words (in the title or also in the text, from all feeds or from one), the app can notify you, mark it as a favorite, save it for later, mark it as read or move it to the trash. “Test with the articles I already have” says how many match.
  • Notifications: from feeds with “Notify of new articles”. When only a few arrive, each article gets its own notification with the buttons “Mark as read” and “Add to favorites”; tapping it opens the article. When many arrive, a single notification with the list.
  • Trash: restore articles or empty it.
  • Feed status: first those failing, those that haven't published for a while and the paused ones.
  • Summarize unread with AI: a summary by topic that says which ones are worth reading.
  • Export the articles in this tab: saves them to an HTML file.
  • Import OPML and Export OPML.

When you mark many articles as read at once (all of them with Mark all as read, those in a folder or a feed, or with “Mark the ones below as read” or “the ones above”), a message with the “Undo” button appears at the bottom for a few seconds.

Paid subscriptions and news account

  • News sites you subscribe to (Settings, News, Full article and subscriptions): add the site, sign in with your account on its website (it opens inside the app) and tap Done. From then on, its full articles are downloaded with your subscription.
  • News account (Settings, News): syncs your feeds, read status and favorites with FreshRSS, The Old Reader, Miniflux or Nextcloud News. Each service is explained in that same section. Feedly and Inoreader don't allow it: export your OPML there and import it here.

Radio

In the side menu, Radio. More than 50,000 stations from all over the world from the free radio-browser.info directory (no account and no ads), plus any you add by hand. Its tabs are at the bottom: Favourites, Explore, Search, History and Schedule. In More options: Add a station by hand, Update favourites, Import stations (M3U or PLS) and Export favourites (M3U).

Tapping a station starts playing it and you stay in the list, with what is playing in the mini player at the bottom (so you can try stations one after another). Tapping the one already playing opens its player. If you prefer the player to open every time, turn it on in Settings, Radio.

Each station says its state first (Playing, Recording, Favourite or whether it was not working at the last check) and then its name, country, genres and quality (for example MP3, 128 kbps).

The tabs

  • Favourites: your stations, with folders as in Podcasts (“New folder”, “Folder options” and “Play this folder”) and the “Order” button: manual, by name or the ones you listen to most. With manual order, each station has Move up one position, Move down one position, Make it first and Make it last.
  • Explore: stations from your country (the “Your country” button changes it), the most listened to in the world, the most voted, trending, what people are listening to now and new ones, plus the By genre, By country and By language lists, with a field to filter them. In a list of stations, the “Order” button chooses most listened to, most voted, trending, by name or best quality. At the end of each list, “Load more stations”. “Go up to” or Back return to the previous level.
  • Search: type the name and press Search (or the keyboard’s search key). The “Filters” button narrows it down by country, language, genre, minimum quality and order, and also lets you search without a name (for example, all jazz stations from France).
  • History: the “Show” button chooses between the stations you listened to, the songs that played (on stations that send the title of what is playing) and your recordings. Each view has its button to clear it and, while recording, “Stop recording”.
  • Schedule: your alarms and scheduled recordings, and the next one. “New alarm” and “New scheduled recording” buttons.

Station actions

Play (or Go to the player if it is already playing), Add to or Remove from favourites, Move to a folder (in Favourites), Remove from history (in History), Record or Stop recording, Wake me up with this station, Songs that have played, Vote for this station, Station information, Open in browser, Share, Copy the stream address, Create a home screen shortcut and, for stations added by hand, Edit the station. As in the rest of the app, in Settings, TalkBack actions you choose which ones appear when swiping.

The radio player

  • At the top, the station name (heading), its state (“Live”, “Paused”, “Connecting…” or “Connection lost. Reconnecting…”) and the song that is playing. TalkBack says the new song when it changes, without moving focus (you can turn this off in Settings, Radio).
  • Previous station, Play or Pause and Next station: they go through the list you started listening from (or your favourites). Headphone and notification buttons do the same. Long-pressing Play chooses a sleep timer.
  • Add to or Remove from favourites, Sleep timer, Record or Stop recording, Search the song online (also copy or share it), Songs that have played, Equalizer (the system one, if the phone has it) and More options (the other station actions and Stop the radio).
  • With a keyboard: Space plays or pauses, and Control with the left and right arrows changes station.
  • If the connection drops, it reconnects by itself (Settings, Radio, “If the connection drops”). After a long pause, resuming goes back to the live broadcast.

Recording

“Record” saves the station as it arrives (MP3, AAC or OGG, with no loss of quality) until you stop it or for the minutes you choose. It records separately: you can keep listening to another station, a podcast or a book. While recording there is a notification with “Stop recording”. Recordings are in History, Show: Recordings, with Play, Save to the library, Share, Rename and Delete. Stations that stream in segments (HLS) cannot be recorded, and the app says so.

Alarm clock and scheduled recordings

  • In Schedule, or with “Wake me up with this station”. You choose the station, the time (typed with the keyboard), the days (once, every day, Monday to Friday, weekends or the ones you tick), how long it plays or records, and whether it is on.
  • The alarm rings even if the phone is idle or locked: the station starts quietly and gets louder over one minute (Settings, Radio), and a screen shows Turn off the alarm and Snooze (5, 10, 15 or 20 minutes, in Settings). If there is no internet or the station does not respond, the phone’s alarm sound plays so you do not oversleep.
  • Each schedule has Turn on or Turn off, Edit, Try it now (alarms) and Delete. They are kept when the phone restarts.
  • Android 13 and later ask for permission to show notifications when you set the first alarm; without it the alarm still plays, but without the notice with Turn off and Snooze.

Stations by hand, M3U and shortcuts

  • Add a station by hand: name, address, genre and website. Any address works: the stream (MP3, AAC, AAC+, Ogg, Opus, FLAC, HLS…), a .pls, .m3u, .asx or .xspf playlist, or the station's web page, and you do not need to type http. The app checks what is at the address (it does not trust the extension), follows playlists, and on a web page looks for the stream (in the page, its players and its scripts) and checks each one; if there are several, it lets you choose. If the name, genre or website are empty, it takes them from what the station says. If it cannot check that it plays, it says why and asks whether to save it anyway. It is saved in Favourites.
  • Stations play like in desktop players: the app identifies itself with its own name (some servers reject Android's), follows redirects between http and https, tries without encryption if the station's certificate is not valid, and includes a backup decoder for formats the phone cannot read (such as the MP2 of some HLS stations). If it still cannot play, the player says why (the station refuses the connection, the server is down or the format cannot be played) instead of retrying for nothing.
  • From Share in another app, choose Lector Universal: add to Radio to add that address (also the station's web page).
  • Import stations reads M3U or PLS lists (from other radio apps) and adds them to favourites, with their folders if they have them. Export favourites saves them as M3U, which almost every player understands.
  • Create a home screen shortcut puts an icon on the home screen that starts the station with one tap.

Importing OPML

“Import OPML”, in the More options of News or Podcasts, opens the same screen in both cases. The app checks each feed in the file and decides whether it is news or a podcast; then you see the list to review it before importing.

  • Each feed is a checkbox that says where it will go (News or Podcasts), in which folder and whether you already have it (those you already have are unchecked). Double-tap to import it or not.
  • Its actions: Move it to News or Move it to Podcasts, Move to a folder, Change the name and Show the address.
  • In More options: Import (says how many), Choose all, Choose none, and move the chosen ones to News, to Podcasts or to a folder.

The folders in the file are kept. Export OPML saves your feeds or your podcasts with their folders.

Artificial intelligence, OCR and more

  • Choosing the AI (Settings, Artificial intelligence): the easiest option is to download the app's AI (Gemma 4, 2.6 GB): it works offline and nothing leaves the phone, but it needs a 64-bit phone with about 6 GB of RAM. If the phone has its own AI (Gemini Nano), it can be used. You can also enter your Gemini key (free at aistudio.google.com), OpenAI key or Claude key. “Check the AI” says which one will be used.
  • AI button while reading: summarize this chapter, summarize what you have read so far (without revealing what comes next), ask about this chapter, explain or translate the paragraph. In articles and texts, it summarizes or answers about the whole text. The answer appears in a window with “Ask more”, “Copy” and “Close”.
  • Images: on an image, “Describe the image” offers to describe it here with AI, read the text in it (OCR), send it to another app to describe it (Be My Eyes, Gemini, Lookout…) or view it. In PDFs, each page has “Describe page”.
  • Scanned PDFs: when you open one, the app warns you and offers to recognize the text of the whole PDF (OCR, offline). The result is a new document in the library. It is also in the AI button.
  • Comics (CBZ): each page is a heading with its image. “Describe the image” describes it with AI or reads the text in its speech bubbles, and in the AI button, “Recognize the text of every page” creates a document with all the text.
  • Export to audio: Export button, “Export to audio”. You choose a folder and one M4A file per chapter is created with that book's voice; progress appears in the notification.
  • Sync with your server (WebDAV): in Settings, Library and sync, enter the address of a WebDAV folder (for example the WebDAV Server package on Synology, or Nextcloud), your user name and your password. Where you are and the bookmarks of each book are shared between your devices.
  • Widget “Continue reading” for the home screen.

Supported formats

  • Books: EPUB 2 and 3, Kindle (MOBI, AZW, AZW3, PRC), FictionBook (FB2 and FB2.ZIP) and CHM.
  • Documents: PDF, Word (DOCX and the old Word 97-2003 DOC), OpenDocument (ODT), RTF, Windows Write, text (also CSV, and old MS-DOS TXT files with their accents), HTML and MHT, Markdown and reStructuredText.
  • Comics: CBZ, or a ZIP with only images.
  • Presentations and spreadsheets: PowerPoint (PPTX), Impress (ODP), Excel (XLSX) and Calc (ODS).
  • DAISY 2.02 and DAISY 3, in a folder or ZIP, text only, audio only, or text and audio synchronized.
  • EPUB 3 with synchronized narration (Media Overlays: text and human audio together): they open in the player like a DAISY text and audio book, with the text following the voice, the narrator, the table of contents and the pages. In Settings, Documents, “EPUB with narration: use its audio”: if you turn it off, they open as text.
  • Braille books: ONCE BRA and BAN files (from the ONCE Digital Library, EBrai or QuickBraille), BRF and PEF. They are turned into text (uncontracted Spanish braille): the page numbers of each sheet are removed and kept as pages to navigate (“Page 9, print 5”: the braille page and the printed book’s page), lines are joined into paragraphs, words split with a hyphen are joined and centered titles become headings. In Settings, Documents, “Braille books: turn them into text”: if you turn it off, their dots are shown as they are. Contracted English braille (grade 2) is not turned into text.
  • Audio: M4B and M4A with chapters, MP3 with chapters, OGG, OPUS, FLAC, WAV and others; M3U and CUE playlists; audio folders.
  • ZIP with a book, with several documents or with audio.

Books with DRM (store copy protection) can't be opened, and the app says so. Password-protected documents ask for the password when you open them.

Settings

In the side menu, Settings. At the bottom there is a tab for general settings and one for each section, in the order of the sections (the one in Home and sections). The tabs are always shown whole: if they do not all fit on your screen, the last ones go to a final “More” tab, which says which one you have chosen. From the side menu of a section, Settings opens on that section’s tab. The tabs: General (what affects the whole app: General, Home and sections, Read aloud, ElevenLabs, TalkBack actions, Artificial intelligence and Backups), Library (Library tabs and types, Library voice, Text appearance, Navigation and TalkBack, Audiobooks and DAISY, Documents and Library and sync), Shared, Podcasts, News (starting with the News voice) and Radio. Back in a section returns to its tab; on another tab, to the tab Settings opened on; and on that one it leaves Settings. Each section has its options:

  • Library tabs and types: which type tabs appear at the top of the Library and in which order, and your own types. Explained in Library.
  • Shared (its own tab): the Shared voice, where what you share with the app goes (Shared or the library, as before), what to do when it arrives (open it, open it and read it aloud, or just save it), whether read items are deleted automatically and the TalkBack actions in Shared.

In “Section order”, a double tap shows or hides the section on Home (it reads as a switch) and you move it with the TalkBack actions Move up one position, Move down one position, Move to first and Move to last, or by touching and holding it. When you move it, focus stays on it and its new position is announced.
  • General: app language and theme, open the last book on startup, keep battery saving from stopping reading, sounds, updates and Report a problem: if the app closes suddenly, the error is saved only on the phone and the next time it offers you to see it and send it yourself (by email or however you like); the app never sends anything by itself.
  • Text appearance: colors (including high contrast, a black screen to listen while saving battery and Your own colors: you choose the color of the text, background, links and highlight from a list of names or by typing its code, and each one says its contrast and whether it reads well), text size and font (also Atkinson Hyperlegible, made for low vision, OpenDyslexic, for dyslexia, Lexend and a font of your own, a TTF or OTF file), bold, line spacing, letter spacing, margins, paragraph spacing, justify, keep the screen on, orientation and full screen.
  • TalkBack actions: explained below.
  • Navigation and TalkBack: navigation bar, what double-tapping a paragraph does, paragraph actions, button rows while reading, buttons that go to the More menu, volume keys, say heading levels, say the page or result when jumping, wrap-around navigation, sounds when reaching an element, what to say about each paragraph, bookmark sound and selectable text.
  • Read aloud (in General: the voice of the whole app): what to do when TalkBack speaks, engine, voice language, voice (each one says whether it works offline or needs the Internet), speed, pitch, pauses, highlight the sentence, have the screen follow the voice, voices by language, heading pitch, page numbers, what to skip (footnotes, web addresses, parentheses and brackets), pronunciation dictionary, system speech settings (to install voices) and When the screen turns on: keep reading, pause reading when the screen turns on or pause it when the phone is unlocked (like in @Voice). On some phones the screen turns on by itself when a notification arrives; then “when the phone is unlocked” is better.
  • Audiobooks and DAISY: speed, Back and Forward seconds, rewind on resume, headphone buttons, skip silence, play on open, shake to extend the sleep timer and “When the screen turns on” (keep playing or pause when the screen turns on or when the phone is unlocked; it applies to audiobooks and podcasts, the radio keeps playing; it is also on the Podcasts tab).
  • Podcasts: Refresh podcasts (its own frequency, separate from the news), where new episodes go, downloading them, download on Wi-Fi only, how many downloaded episodes are kept per podcast (the oldest are deleted automatically, except favorites and those in the queue), delete the download when finished, continue with the queue, when an episode counts as played, speed, how often to refresh and the podcast account.
  • News (RSS): the news voice, Refresh the news (manually only; every 5, 10, 15, 30 or 45 minutes; every 1, 2, 3, 6 or 12 hours; once a day; or Custom, typing the minutes, 5 or more; News and Podcasts each have their own, and with battery saving Android may delay it a little), Wi-Fi only, notifications, mark as read on open, oldest first, show only unread in Feeds, when read articles are deleted, what is said about each article, read aloud when opening an article, full article, news sites you subscribe to and the news account.
  • Radio: open the player when you play a station or stay in the list, announce the song that is playing, save the songs, hide stations that do not work, ask before playing on mobile data, what to do if the connection drops, and for the alarm clock, raise the volume gradually and the Snooze minutes.
  • Artificial intelligence: which AI to use, the downloaded AI, use the graphics card, check the AI and your keys.
  • Documents: tables with headers (“Column: value”), image descriptions, split long paragraphs, join PDF lines, text line by line and clear the document cache.
  • Backups: create and restore backups, and whether keys go in the Android backup. Explained below.
  • Library and sync: whether PDF, Word, RTF and text files are books or documents, watched folders and sync with your server (WebDAV).

More natural voices

Reading aloud uses the speech engine you choose from those installed on your phone: Google’s, Samsung’s, Vocalizer, eSpeak, MultiTTS… The app has no voices of its own and downloads no voices: it uses yours. If you want more natural voices without internet, you can install an engine such as SherpaTTS (on F-Droid), with Piper voices, and choose it in Read aloud, Engine.

ElevenLabs (optional, in Settings, General, ElevenLabs): very natural cloud voices with your own elevenlabs.io account and API key (the app has no server or key of its own). Enter the key, tap “Check the key and the credits” and choose “ElevenLabs” as the engine in Read aloud: it is used in the whole app (books, Shared and news) except where you choose another voice, in a section’s or a book’s voice. Then choose a voice from your account. This is how it works:

  • Each paragraph is requested from ElevenLabs and saved: going back or reading it again costs no credits. Speed and pitch are set by the app, instantly.
  • It uses credits from your account: the free plan gives about 10,000 characters a month (about 5 pages). “Flash v2.5” uses half. You can give your key a monthly limit at elevenlabs.io.
  • If it fails (no credits, no connection, wrong key), it says so with the phone voice and keeps reading with it; or it stops, if you choose so. Pressing Play again tries ElevenLabs again.
  • Privacy: what is read with ElevenLabs is sent to its servers and kept in your account history. With the phone voices nothing leaves the phone.
  • Export to audio always uses the phone voices.

TalkBack actions

Here you choose, for each place in the app, which actions appear when you swipe up or down with TalkBack and in what order. The places are: books and folders in the library, reader paragraphs, bookmarks and notes, online catalogs, news articles, feeds and folders, podcasts and search results, podcast episodes, podcast folders, radio stations, station folders, songs, recordings, and alarms and scheduled recordings. Each place says how many actions appear.

  • Each action is a switch: double-tap it to show it or not.
  • Those that appear are sorted with their Move up one position, Move down one position, Move to first and Move to last actions, or by holding.
  • Whatever you remove is still in each element's menu (double-tap and hold).
  • “Reset”, in More options, goes back to the usual actions.

For example, you can remove AI from paragraphs, or put “Refresh” directly on each podcast or “Move to a folder” on each feed.

Backups

In Settings, Backups. A backup saves what you choose to a single file, so you can have the app exactly the same on another phone, or go back if something goes wrong. You save the file wherever you want (on the phone, on a card, in Google Drive or on your Synology, with the Android file picker); the app does not send it anywhere.

Create a backup

First you choose what to save. Each part is a checkbox that says what it contains and its current size:

  • Library: books, folders, positions, bookmarks, notes, collections, series, pronunciation and reading statistics.
  • Books saved in the app: what is inside the app itself (catalog downloads, web pages, clipboard or shared texts and scanned documents).
  • Podcasts: subscriptions, folders, played episodes and where you were, queue and favourites. Not downloads: they are downloaded again.
  • News: feeds, folders, articles, read, favourites and read later.
  • Radio: favourites, history, songs, alarms and scheduled recordings.
  • Radio recordings: the recorded audio files.
  • Listening statistics: time with podcasts, news and radio.
  • Settings: every app setting.
  • Keys and passwords: the cloud AI keys and the passwords for sync, catalogs and private podcasts.

Then, the password. With a password, nobody can open the backup without it: it is encrypted with 256-bit AES and the key comes from your password with PBKDF2 and 600,000 rounds, so guessing passwords is very slow. It must have at least 8 characters and you type it twice. If the backup contains keys and passwords, the password is required; otherwise you can choose “No password”, but whoever has the file will be able to see your data. If you forget the password there is no way to recover it.

Finally, you choose where to save the file (it ends in .lucopia). While it saves, the wait window says which part it is saving; when it finishes, it says its size, what it contains and whether it has a password.

Restore a backup

Choose the file; if it has a password, type it. The app says when the backup was made, on which phone, with which version and what it contains. With “Choose what to restore” you check what to recover: what you check replaces what you have now on this phone, and what you leave unchecked stays as it is. Before changing anything, the app checks the whole backup; if it is damaged, cut short or the password is wrong, nothing is touched. When it finishes, the app restarts with what was restored.

Books you opened from the phone's folders are not inside the backup: the library remembers where they were, so copy those files to the new phone as well. Books inside the app are included, in “Books saved in the app”. Older backups (.json file, up to version 1.0.9) can also be restored.

Undo the last restore

Before restoring, the app saves how everything was (except books saved in the app and recordings), on the phone. If you are not happy with what was restored, “Undo the last restore” puts it back. This option only appears when there is something to undo.

Android backup

Android also saves automatically, in your Google account, the library, podcasts, radio, statistics and settings, and moves them to your new phone when you set it up (when transferring data from one phone to another, also the news and the books saved in the app). Keys and passwords are not included in that backup unless you turn on “Include keys and passwords in the Android backup”. You can change it at any time: when you turn it off, they stop leaving this phone.

Updates

The app checks for new versions when it opens (at most every 6 hours; turn it off in Settings, General). To check whenever you want, use About, Check for updates, or Settings, General, Check for updates. If there is one, it shows what it brings with the Update and Later buttons (in the automatic check, also Skip this version). When you update, it downloads it, checks that it is genuine and opens the Android installer; the first time, Android asks you to allow installing apps from this source. What's new in each version is in About, What's new.

In Settings, General, “Look for updates on” you choose where the app updates from:

  • Both: own server and GitHub (the default): asks both at once and offers the newest version; if one does not answer, it uses the other.
  • Own server only: the author's, or the one you type in “Own server address”.
  • GitHub only: the latest version published in the app's GitHub repository.
  • A custom address: a web folder with version.json and the APK, or a GitHub repository (https://github.com/user/repository).

Wherever it comes from, the app checks that the download is the published one (size and SHA-256) and that it is signed with the same key as the installed app; Android does not allow installing over an app with a different signature either. When a version is offered, it says where it comes from.

Troubleshooting

I can't choose the Download folder

Android doesn't allow it. Create a subfolder (for example Download/Books or Documents/Books), move the books there and add that folder.

A book no longer opens

If you moved or deleted the file, the app can no longer find it. Remove it from the library and add it again.

The voice is silent or there are no voices

Install or update a speech engine (for example Speech Services by Google) and its voices from Settings, General, Read aloud, System speech settings.

Reading or audio stops with the screen off

Tap Settings, General, “Keep battery saving from stopping reading”. If it keeps happening, also remove the battery restriction from the speech engine.

A document looks wrong or has no headings

Try other options in Settings, Documents, and then clear the document cache so books are converted again.
